# Privacy

Bundled Python scripts run locally against the file paths the user supplies. They do not upload files, extract chat payloads, or write recovered records; they report bounded inventory metadata, hashes, offsets, and requested exact-identifier hit counts. Scan output may still contain local paths and may be shown in the ChatGPT conversation.

When Google Drive or Desktop Commander is connected, those providers process requests under their own service terms and account permissions. Drive reads may be visible in account activity. Use only the minimum authorized data needed and avoid sharing credentials, backup keys, or unrelated personal material. This plugin does not operate a telemetry service.
